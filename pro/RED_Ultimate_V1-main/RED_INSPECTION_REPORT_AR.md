## نقاط القوة الأمنية

### 1. تشفير الطرف لطرف (E2EE)
- استخدام **libsignal protocol** للتشفير端到端
- مفاتيح **Kyber-1024** للكمبيوتيشن المقاوم للمستقبل (PQ-safe)
- **Sender Keys** للمجموعات المشفرة
- لم يخزّ server النص أبداً - server لا يرى الرسائل

### 2. حماية المفاتيح المحلية
- **Android Keystore** لتخزين المفاتيح (غير قابلة للخروج)
- تشفير سجلات SQLite using **AES-256-GCM**
- **ProtocolRecordCipher** لتشفير جميع السجلات الحساسة
- **SecureStore** لتشفير إعدادات الجلسة والرموز المميزة

### 3. التحقق من الهوية
- **Safety QR Codes** لتأكيد الهوية face-to-face
- **ECDSA certificates** للأجهزة المعتمدة
- **Fingerprint-based verification** مخزن بشكل محلي

### 4. حماية الخصوصية
- **FLAG_SECURE** لمنع لقطات الشاشة
- **لا يوجد رقم هاتف مطلوب** للتسجيل
- **Local server discovery** للخوادم المحلية فقط
- **UUIDv7** للمعرّفات غير القابلة للتتبع

### 5. حماية الوسائط
- **AES-GCM** لتشفير المرفقات ورسائل الصوت
- **SHA-256** للتحقق من سلامة الملفات
- مفاتيح openssl عشوائية لكل مرفق
- ممسح شامل للمفاتيح بعد الاستخدام
