### 4.1 تنظيف الفهرس (آمن، خطوة واحدة)
قواعد `.gitignore` المُصلَحة لا تُلغي تتبّع الملفات القديمة. أُعِدّ سكربتًا
**لا يحذف أي ملف من القرص** (‏`git rm --cached` فقط)، وقائمته تُشتقّ من git نفسه:
```powershell
# 1) مراجعة فقط — لا تغيير
powershell -ExecutionPolicy Bypass -File .\cleanup-git-tracking.ps1
# 2) التنفيذ بعد مراجعة القوائم
powershell -ExecutionPolicy Bypass -File .\cleanup-git-tracking.ps1 -Apply
```
يطبع تحذيرًا أحمر لو وُجد أي ملف أسرار متتبَّعًا. **لا يعمل commit ولا push.**
