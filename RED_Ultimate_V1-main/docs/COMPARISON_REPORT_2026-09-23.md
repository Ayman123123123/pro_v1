## 7) خطة الدمج الموصى بها (إن اخترت التنفيذ)

1. `git merge origin/arena/01a0a0cf-pro-v1` في فرع جلستي (يبقى كل عمل main + إصلاحاتي أساساً)
2. حل التعارضات حسب خريطة القسم 4 (main يفوز في الـ262 المتعارضة)
3. استعادة كل ملفات القسم 2 تلقائياً (الدمج يجلبها بلا تعارض لعدم وجودها في main)
4. **حذف المخلفات** (قسم 5) في commit منفصل موثق
5. التحقق بعد الدمج: `tsc --noEmit` للوحة + مسح هجرات SQL (الآن 68+57 → فحص تكرار أرقام V) + حصر استيرادات `app/` و`red-app/`
