About Key Words:  1. You can input multiple keywords and special symbol like "[E], [T], [*], [N]".
Space is also avalable.
  2. [E] is used to match Enter. e.g. "number is[E]" is used to match the number under line "number is".
  3. [T] is used to match Table character.
  4. [*] is userd to match anything betwen the keywords.
  e.g. "number is[*]number is " is used to match the number after the second keyword "number is ".
  5. [N] is used to match the number at the specify position.
  e.g. "number is [*]number is [N], abc" is used to match "456" in SMS "number is 123 and number is 456, abcdefg...".
  6. It can match the number after a keyword or in front of a keyword.
  It is depending on the position of the [N] symbol.If the [N] symbol is follow close behind a keyword, it match a number after the keyword. If a keyword is follow close behind the [N] symbol, the [N] sysbol match a number in front of the keyword. Normally, we use [*][N] to match a number in front of the keyword.
  e.g. "is number 1[*][N] is number 2" is used to match "456" in SMS "123 is number 1 and 456 is number 2".
 
About Send Text:  1. When you using the "Call" type, the send text can be null or the DTMF number
you want to dial after call out.
2. The DTMF number's format is "pN,Number". Among them, "N" is the waiting seconds.
e.g. If we want to call 10086 and after 8 seconds we dial 1, then after 8 senconds we dial 1 again, at last,we wait 15 seconds and dial 2. The setting should be as follow.
Dest Number: 10086.
Send Text: p8,1,p8,1,p15,2 .
 
About Write SIM Card: 1. It is available only if the sim card support it.
2. When matching a phone number, the device will write it to SIM card automaticly.
Please do not pull out the SIM card at the moment.
