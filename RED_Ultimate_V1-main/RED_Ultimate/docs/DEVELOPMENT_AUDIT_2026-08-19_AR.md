# تدقيق التطوير — 2026-08-19

يركز هذا التدقيق على Backend وCompose والاختبارات وعقود API وSFU. النتائج التشغيلية الحالية يجب أن تُعاد عبر بوابة CI بدل الاعتماد على تقارير تاريخية.

## منهجية التحقق

1. `docker compose config --quiet`.
2. فحص مخطط JPA/Flyway.
3. اختبارات backend.
4. فحص وبناء لوحة الإدارة.
5. فحص صياغة SFU وملفات التشغيل.
6. بناء Android مع dependency verification.

لا تُعتبر الميزة مكتملة قبل نجاح الفحوص المناسبة لها وتوثيق أي عائق متبقٍ.
