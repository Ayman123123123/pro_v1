### Android (جديد بالكامل)
| المكوّن | الوصف |
|---|---|
| `StickerApi.kt` | API client + DTOs |
| `StickerPicker.kt` | منتقي احترافي: تبويب حزم (مثبّتة + متاحة) + تثبيت + شبكة ملصقات 5×N |

| إرسال E2EE | منح وصول + STICKER message مشفّرة |

---

## التدفق

1. المستخدم يضغط زر الملصقات (+) في شريط الكتابة
2. يظهر `StickerPicker`: حزم مثبّتة + متاحة (مع زر تثبيت)
3. يختار حزمة → تظهر شبكة ملصقاتها
4. يضغط ملصقاً → يُمنح المستقبل وصولاً للوسائط → تُرسل رسالة `STICKER` مشفّرة E2EE
5. المستقبل يرى الملصق (إيموجي كبير كمعاينة)
