# المكالمات

## الأنواع

| النوع | المسار |
|---|---|
| صوت فردي | WebRTC عبر `/ws/calls` وSFU عند الحاجة |
| فيديو فردي | WebRTC عبر `/ws/calls` |
| مؤتمر | WebRTC مع SFU وتوزيع الوسائط |
| بث مباشر | مسار البث مع SFU |

## المكونات

- `red-app/.../calls/`: إشارات المكالمات، WebRTC، الصوت، الكاميرا وحالة الواجهة.
- `backend-server/.../calls/`: سجل المكالمات وتسليم الإشارات.
- `media-sfu/`: توجيه الوسائط.
- `coturn`: TURN للاتصالات التي تحتاج ترحيلًا.

## التحقق

اختبر offer/answer وICE والرنين والقبول والرفض وإنهاء المكالمة على جهازين. لا تعتبر مكالمة ناجحة اعتمادًا على فحص البناء وحده.
