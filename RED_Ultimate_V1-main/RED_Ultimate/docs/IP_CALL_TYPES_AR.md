# أنواع مكالمات الإنترنت

تستخدم المنصة WebRTC للمكالمات الصوتية والمرئية والمؤتمرات والبث. لكل نوع واجهة وحالة مستقلة مع عقد signaling موحد.

## القواعد

- المكالمة الفردية لا تنشئ طبقات simulcast إضافية بلا حاجة.
- المؤتمر والبث يستخدمان SFU لتوزيع الوسائط.
- لا تُعرض عناصر تحكم غير متاحة لنوع المكالمة الحالي.
- يجب تنظيف موارد الصوت والكاميرا وPeerConnection عند الإنهاء.

## التحقق

اختبر جودة الصوت والصورة، الرنين، الانتقال بين الشبكات، TURN، وتعدد المشاركين على أجهزة حقيقية.
