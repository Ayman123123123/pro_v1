# مكالمات الإنترنت في يونس — كل نوع كما يعمل على الشبكة

لا PSTN هنا. خمسة أنواع، لكل واحد واجهة وسلوك مطابق لما يعرفه الناس من واتساب وتلجرام وزووم وإنستغرام وX.

| النوع | المرجع | الرنين | ماذا يرى المستخدم | الأزرار |
|---|---|---|---|---|
| صوت فردي | واتساب / تلجرام | يرن الجهاز | صورة + نبض + مؤقت | رفض / قبول، ثم كتم وسماعة وتعليق وإنهاء |
| فيديو فردي | واتساب | يرن الجهاز | الطرف الآخر ملء الشاشة + نافذتك صغيرة | قبول، أو قبول بدون كاميرا، ثم كتم وكاميرا وتدوير وإنهاء |
| مساحة صوتية جماعية | واتساب Voice Chat / X Spaces | **لا رنين جماعي** | منصة متحدثين + مستمعين | انضمام هادئ، رفع يد، تفاعل، مغادرة |
| مؤتمر فيديو | زووم / Meet | دعوة اختيارية لا رنة هاتف | شبكة فيديو أو تركيز المتحدث | كتم، كاميرا، شبكة، مغادرة |
| بث مباشر | إنستغرام / يوتيوب لايف | بطاقة «بدأ البث» | شارة LIVE + عدد مشاهدين + دردشة + قلوب | المذيع: كاميرا وإنهاء — المشاهد: مشاهدة وتعليق وقلب |

## قواعد لا تُخلط

- الرنين الكامل للمكالمة الفردية فقط.
- المجموعة لا تُرن كل الأعضاء؛ يبدأ الصامتون بالانضمام.
- البث اتجاه واحد: مذيع → مشاهدون، ليس شبكة مكالمة.
- لا لوحة DTMF على مكالمات الإنترنت (تلك لـ PSTN/IVR).
