# مكالمات الإنترنت في يونس — كل نوع كما يعمل على الشبكة

لا PSTN هنا. خمسة أنواع، لكل واحد واجهة وسلوك مطابق لما يعرفه الناس من واتساب وتلجرام وزووم وإنستغرام وX.

| النوع | المرجع | الرنين | ماذا يرى المستخدم | الأزرار |
|---|---|---|---|---|
| صوت فردي | واتساب / تلجرام | يرن الجهاز | صورة + نبض + مؤقت | رفض / قبول، ثم كتم وسماعة وتعليق وإنهاء |
| فيديو فردي | واتساب | يرن الجهاز | الطرف الآخر ملء الشاشة + نافذتك صغيرة | قبول، أو قبول بدون كاميرا، ثم كتم وكاميرا وتدوير وإنهاء |
| مساحة صوتية جماعية | واتساب Voice Chat / X Spaces | **لا رنين جماعي** | منصة متحدثين + مستمعين | انضمام هادئ، رفع يد، تفاعل، مغادرة |
| مؤتمر فيديو | زووم / Meet | دعوة اختيارية لا رنة هاتف | شبكة فيديو أو تركيز المتحدث | كتم، كاميرا، شبكة، مغادرة |
| بث مباشر | إنستغرام / يوتيوب لايف | بطاقة «بدأ البث» | شارة LIVE + عدد مشاهدين + دردشة + قلوب | المذيع: كاميرا وإنهاء — المشاهد: مشاهدة وتعليق وقلب |

## قواعد لا تُخلط

- الرنين الكامل للمكالمة الفردية فقط.
- المجموعة لا تُرن كل الأعضاء؛ يبدأ الصامتون بالانضمام.
- البث اتجاه واحد: مذيع → مشاهدون، ليس شبكة مكالمة.
- لا لوحة DTMF على مكالمات الإنترنت (تلك لـ PSTN/IVR).

## ما يكتمل الآن في المسار الحي

- بدء مساحة/مؤتمر من المجموعة ينشئ الغرفة على السيرفر ثم يدعو الأعضاء عبر `/ws/calls` (`CONFERENCE_INVITE`) — انضمام هادئ لا رنين جماعي.
- البث يُسجَّل في السجل كـ `LIVE`، والمشاهد يستدعي `/api/livestream/{id}/join` قبل الإشارة.
- دعوة البث تصل كبطاقة مشاهدة (`LIVE_INVITE`) لا كمكالمة هاتف.
- إعادة تفاوض ICE للمكالمة الفردية لا تفتح رنة ثانية.

## طبقة الوسائط (ما يُطبَّق الآن في SDP والمحرّك)

| النوع | صوت | فيديو | خوارزمية الجودة |
|---|---|---|---|
| صوت فردي | Opus 32kbps + FEC + DTX + أحادي | لا | MOS (G.107) → تكييف السرعة |
| فيديو فردي | Opus 40kbps + FEC | H.264 أولاً + simulcast | نفس MOS |
| مساحة | Opus 32kbps + DTX | لا | بدون فيديو |
| مؤتمر | Opus 48kbps + FEC | VP9-SVC أولاً | طبقات L2T3 |
| بث | Opus 64kbps ستيريو | VP9-SVC + بدء أعلى | simulcast للمذيع |

- تذكرة SFU للغرف: `GET /api/sfu/groups/rooms/{roomId}/ticket`
- mediasoup يقبل Opus FEC/DTX وVP9 بالإضافة إلى VP8/H.264
- عميل أندرويد `SfuMediaClient` ينضم وينشر عبر `/sfu`؛ إن تعذّر SFU يبقى المسار الشبكي (mesh) للمؤتمرات الصغيرة
- كتم المذيع على SFU = `pauseProducer` / `resumeProducer` دون هدم النقل
- المكالمة الفردية: نغمة رنين صادرة (TONE_SUP_RINGTONE) ومهلة 45 ثانية ثم فائتة
- المساحة: المضيف متحدث، المدعو مستمع ويرفع يده — لا رنين جماعي ولا زر كاميرا
