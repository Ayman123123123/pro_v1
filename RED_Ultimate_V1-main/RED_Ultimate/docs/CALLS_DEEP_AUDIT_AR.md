# تدقيق المكالمات

## النطاق

يشمل التدقيق التطبيق، الخادم، قواعد البيانات، الإشعارات، واجهة المكالمة، WebRTC وSFU.

## مسار المكالمة

```text
المتصل -> signaling WebSocket -> backend -> إشعار/اتصال المستقبل
       -> offer/answer وICE -> WebRTC/SFU/TURN -> audio/video
```

## نقاط الفحص

- صحة `targetUserId` وعقد رسائل signaling.
- منع تكرار offer والاتصالات القديمة بعد إعادة الاتصال.
- مهلات الرنين والقبول والرفض والإنهاء.
- تنظيف PeerConnection وAudioManager وForeground Service.
- تمرير ICE عبر TURN عند اختلاف الشبكات.
- حفظ سجل المكالمة بعد الإنهاء.

## بوابة القبول

شغّل اختبارات الوحدة، ابنِ APK، ثم نفّذ مكالمة صوت وفيديو فعلية بين جهازين مع logcat وسجل backend. عالج أي فشل في مرحلة واحدة قبل الانتقال إلى التالية.
