# Product UX roadmap

## Visual language

المحتوى أولاً: يستخدم اللون الزمردي للإجراء الأساسي والحالة الآمنة، والذهبي للتنبيهات التشغيلية، والأحمر للأخطاء والأفعال المدمرة. لا تستخدم خلفيات زخرفية خلف النص.

## Product areas

1. الهوية والموافقة.
2. الرسائل والمجموعات.
3. المكالمات الصوتية والمرئية داخل المنصة.
4. القصص والبث والمحتوى الاجتماعي.
5. الوسائط والنسخ الاحتياطي والإعدادات.

## مراحل العمل

- توحيد المكونات في `red-app/`.
- تثبيت عقود API وWebSocket.
- تحسين الوصولية والأداء والتوطين العربي.
- اختبار التدفقات الأساسية على جهازين حقيقيين قبل الإصدار.
