# لوحة إدارة RED

لوحة React وTypeScript وVite وAnt Design لإدارة منصة RED عبر الخادم الخلفي. تتضمن تسجيل دخول المسؤول، إدارة المستخدمين والموافقات والأجهزة، الإشراف على المحتوى، التدقيق، النسخ الاحتياطية، مركز الأمان، الإشعارات، الوسائط، والبنية التحتية.

## التشغيل والبناء

```bash
npm install
npm run dev
npm run build
npm run check
```

تستمع Vite على `0.0.0.0` لتعمل داخل المعاينة أو خلف Nginx. اللوحة لا تتصل بقاعدة البيانات مباشرة؛ كل الطلبات تمر عبر API الخادم الخلفي.

## الملفات الأساسية

- `src/App.tsx` — shell اللوحة والتنقل.
- `src/api.ts` — عميل API الموحد وتجديد الجلسات.
- `src/hooks/usePolling.ts` — استطلاع واعٍ بحالة التبويب والشبكة.
- `scripts/check-api-contract.mjs` — فحص تعاقد API.
- `scripts/check-frontend-guards.mjs` — حارس الأصول الخارجية، الاستطلاع، والأسرار.
- `scripts/check-app-roles.mjs` — مقارنة المسارات مع قواعد التفويض.
- `Dockerfile` و`dashboard.nginx.conf` — بناء وتقديم الإنتاج.

## التصميم

التسجيل لا يعتمد على رقم هاتف أو OTP. الحساب والجهاز يبقيان في حالة انتظار حتى موافقة المسؤول. تُعرض في اللوحة بيانات تشغيلية مجمعة فقط، ولا تُعرض محتويات الرسائل المشفرة أو المفاتيح الخاصة.
