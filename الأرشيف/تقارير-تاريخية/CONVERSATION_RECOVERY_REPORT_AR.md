## ما تم استعادته إلى المنتج القانوني

تم نقل/إعادة كتابة الوظائف داخل `RED_Ultimate/red-app` و`backend-server` فقط، وليس نسخ شجرة `pro/` أو تطبيقات Signal التاريخية:

- ترتيب وتجربة Dashboard بخمس تبويبات مع الدردشات كوجهة أولى.
- شاشة جهات اتصال فعلية مرتبطة بـ `/api/contacts` وطلبات الإضافة والحضور والمكالمات.
- مجتمعات وقنوات عامة فعلية عبر:
  - `/api/communities`
  - إنشاء مجتمع
  - البحث
  - الانضمام والمغادرة
- البحث المحلي المشفر باستخدام FTS5 مع fallback آمن إلى البحث الخطي.
- mentions وhashtags والرسائل المؤقتة في `RichMessage` وواجهة المحادثة.
- تعديل/إخفاء/كتم/إبلاغ/حذف المنشورات مع عقود backend مقابلة.
- استطلاعات المنشورات وتوسيع نماذج المنشورات وبطاقات الروابط.
- Link Cards مع حماية SSRF وعدم اتباع التحويلات تلقائيًا.
- فحص أمني للوسائط قبل MinIO:
  - الحجم
  - MIME
  - الامتداد
  - magic bytes
  - منع أسماء المسارات
- إصلاح تكامل MinIO الفعلي بإضافة خصائص `red.minio.*` التي كان backend يبحث عنها ولا يجدها.
- تخزين مؤقت مشفر AES-GCM للوسائط المحلية مع إصلاح shadowing كان يجعل نسخة المحادثة لا تعمل كما يجب.
- تحسين التعامل مع الملفات التي لا تعيد MIME أو الحجم من مزود Android.
- توحيد overlays للمكالمات وإضافة:
  - تعدد الأجهزة في WebSocket signaling
  - إلغاء الرنين في الأجهزة الأخرى بعد الإجابة
  - نغمة ورنين واهتزاز للمكالمة الواردة
  - Picture-in-Picture للفيديو
- إضافة تنظيف ملفات MinIO اليتيمة مع dry-run افتراضي آمن.
- توثيق وتحسين الخطوط والألوان السيادية.

## ما لم يتم نسخه عمدًا

هذه العناصر موجودة في فرع المحادثة لكنها ليست مناسبة للنسخ الحرفي:

- `admin_dashboard/**` من المحادثة الأخرى؛ تم الإبقاء على نسخة لوحة الإدارة الموحدة الحالية.
- `AuthFlow.kt` الذي يعيد تسجيل الهاتف وOTP؛ هذا يخالف قرار المشروع الحالي: username/password دون رقم هاتف أو SMS/OTP.
- `features/dinstar/**` في Android؛ إدارة DINSTAR وSMS/USSD مكانها backend ولوحة الإدارة، وليس تطبيق المستخدم.
- مجلد `pro/` الضخم الذي يكرر مشروع Signal التاريخي ولا يدخل build graph.
- شاشات `ui/screens/*` التي كانت scaffolding فارغة.
- شاشة المجتمعات القديمة ذات البيانات الوهمية؛ استُبدلت بواجهة API فعلية.
- نسخ الصور التي ظهرت كـ LFS pointers صغيرة/غير صالحة؛ تم الحفاظ على الأصول العاملة الحالية.
- نسخ `AuthorizedApiClient` التي تستخدم `runBlocking` وتفقد حدود تنزيل الملفات؛ تم الحفاظ على العميل الحالي وإصلاحه بدل استبداله بنسخة أضعف.

## سبب عدم عمل merge آلي كامل

الفرع المصدر لم يكن snapshot قابلًا للبناء بالكامل؛ احتوى على عيوب فعلية، منها:

- `EncryptedMediaCache` كان يستخدم اسم parameter يحجب مفتاح Android Keystore.
- `StoryViewModel` احتوى تعريف `open()` مكررًا ومراجعًا لخصائص غير موجودة.
- `RedDashboard` احتوى imports مكررة ومراجع متغيرات قبل تعريفها.
- `YounesCallService` احتوى import مكسورًا لـ `RingtoneManager`.
- `FeedViewModel` احتوى دوال بعد نهاية تعريف الصنف.
- بعض APIs التي استدعتها الواجهة لم تكن موجودة في backend.
- `DinstarWebSocketBridge` كان يحتوي عنوان IP ثابتًا ومسار `/ws/dinstar` غير موجود في العقد القانوني.

لذلك تم اختيار الأفضل من المصدرين وإعادة كتابة الأجزاء المكسورة بدل إخفاء مشاكلها داخل merge ضخم.
