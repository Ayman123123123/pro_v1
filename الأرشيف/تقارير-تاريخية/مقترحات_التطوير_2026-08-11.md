# 🚀 مقترحات تطوير «يونس» — خارطة طريق أولويات

> **التاريخ:** 2026-08-11
> **الأساس:** فحص عميق لكود التطبيق (red-app + backend) + مقارنة بـ WhatsApp/Telegram/Signal
> **الهدف:** جعل «يونس» الأفضل أمانًا وسهولة وتميزًا

---

## 1) أولويات قصوى (أثر فوري على المستخدم)

### 1.1 إكمال البروفايل
| الميزة | الوصف | الجهد |
|---|---|---|
| **رفع صورة البروفايل** | اختيار/التقاط صورة، رفع مشفر، عرضها في الدردشات وقوائم الأصدقاء | متوسط |
| **إدارة الصورة والاسم من مكان واحد** | شاشة بروفايل كاملة (صورة + اسم + username + حالة/بايو) | متوسط |
| **مشاركة رمز QR للبروفايل** | زر QR يعرض معرّفك لسهولة الإضافة | سهل |

### 1.2 استكمال المجموعات
| الميزة | الوصف | الجهد |
|---|---|---|
| **ردود/تفاعلات (Reactions)** في المجموعات | إيموجي على رسائل المجموعة | متوسط |
| **@all / @admin** | تنبيه كل الأعضاء أو المشرفين | سهل |
| **Slow Mode** | حد زمني بين رسائل الأعضاء | سهل |
| **سجل محادثة للأعضاء الجدد** | مشاركة آخر رسائل عند الانضمام (واتساب 2026) | مرتفع |

### 1.3 وسائط ومرفقات
| الميزة | الوصف | الجهد |
|---|---|---|
| **معرض وسائط للمجموعات** | شبكة كل الصور/الفيديوهات المشتركة | متوسط |
| **ملصقات (Stickers) + GIF** | باقة جاهزة + GIPHY | متوسط |
| **تحميل/حفظ الوسائط بجودة** | فك تشفير + حفظ في المعرض | سهل |

## 2) أمان وخصوصية (تميزك الحقيقي)

| الميزة | الوصف | الجهد |
|---|---|---|
| **تثبيت الشهادة (Certificate Pinning)** | ✅ موجود — أكّد أنه مفعّل في release | مراجعة |
| **قفل التطبيق (Biometric)** | بصمة/وجه لفتح التطبيق | متوسط |
| **قفل محادثة فردية** | حماية محادثة معينة ببصمة | متوسط |
| **منع لقطات الشاشة** | ✅ موجود (FLAG_SECURE) — فعّله لكل الشاشات | مراجعة |
| **ترقية ما بعد الكم** | SQPR ratchet (مثل سيجنال 2025) ليصبح مستوى 3 | مرتفع |
| **نسخ احتياطي مشفر** | تصدير/استيراد مشفر بقاعدة البيانات | مرتفع |
| **إبطال الجلسات عن بعد** | من الأجهزة المتصلة | متوسط |

## 3) تجربة مستخدم (تحسينات يومية)

| الميزة | الوصف | الجهد |
|---|---|---|
| **تثبيت محادثة** | ✅ موجود — أظهر شارة + قسم المثبتة | سهل |
| **بحث داخل محادثة محددة** | ✅ موجود — حسّن النتائج | سهل |
| **مكالمة من قائمة الأصدقاء** | زر اتصال مباشر بجانب كل صديق | سهل |
| **حالة "آخر ظهور"** | إظهار/إخفاء آخر ظهور حسب الخصوصية | متوسط |
| **قراءة الإيصالات لرسالة معينة** | تفاصيل من قرأ (المجموعات) | مرتفع |
| **الرد المباشر على رسالة بمكالمة** | زر رد صوتي/فيديو سريع | متوسط |
| **وضع توفير البيانات** | تعطيل التنزيل التلقائي للوسائط | سهل |

## 4) تنظيم وبنية

| الميزة | الوصف | الجهد |
|---|---|---|
| **تقسيم RedDashboard الضخم** | `RedDashboard.kt` (~2700 سطر) → ملفات منفصلة لكل شاشة | مرتفع (تحسين بنيوي مهم) |
| **إزالة MessageStore القديم** | توحيد التخزين على Room فقط | متوسط |
| **إضافة strings.xml كاملة** | نقل كل النصوص المضمّنة إلى موارد | متوسط |
| **تثبيت توقيع release** | مفتاح خاص منفصل + رفع versionCode | سهل |

## 5) ميزات تميّز «يونس» (لا يملكها المنافسون)

| الميزة | الوصف |
|---|---|
| **الهاتف اليمني (DINSTAR/PSTN)** | ✅ موجود — طوّره (سجل مكالمات، محادثة واردة) |
| **اكتشاف الخادم المحلي** | ✅ موجود — حسّن تجربة الاتصال بالشبكة |
| **الوضع اليمني** | تصنيفات محلية (المدن، القبائل، الأسواق) في الخلاصة |
| **هوية عربية فاخرة** | الذهبي/الزمردي — حسّن التميز البصري |

## 6) خلاصة الأولويات المقترحة

**شهر 1 (أساسيات مكتملة):**
1. رفع صورة البروفايل + شاشة بروفايل كاملة
2. Reactions في المجموعات
3. قفل التطبيق بالبصمة
4. أزرار اتصال في قائمة الأصدقاء

**شهر 2 (تجربة):**
5. ملصقات + GIF
6. معرض وسائط المجموعات
7. وضع توفير البيانات
8. إظهار/إخفاء آخر ظهور

**شهر 3 (أمان + بنية):**
9. نسخ احتياطي مشفر
10. تقسيم RedDashboard
11. ترقية ما بعد الكم (SQPR)
12. توقيع release + توطين كامل

## أولوية واحدة الآن؟

**أقترح أن نبدأ بأهم ميزة للمستخدم الجديد: رفع صورة البروفايل وشاشة بروفايل كاملة** — لأنها أول ما يراه المستخدم وتُحسّن الثقة والهوية، ثم **Reactions** في المجموعات (الأكثر طلبًا).

اختر أي مقترح وسأنفذه فورًا في الكود.
