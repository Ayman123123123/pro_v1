# أرشيف خادم لوحة الإدارة الوهمي — 2026-09-15

خادم Node+SQLite الوهمي للوحة الإدارة (~4.1k سطر) **ميت بقرار معلن**: الملف الحي
`admin_dashboard/scripts/refuse-mock.mjs` (يخرج بكود 1) ينصّ أن YOUNES «لا يشغّل خادم
Node+SQLite بعد الآن» — اللوحة تتحدث إلى Kotlin + PostgreSQL + Mongo + Redis + MinIO.

| المحتوى | الملاحظة |
|---|---|
| `dev-server/` (`server.cjs` + `db.cjs` + `app-routes.cjs`) | عقد مقلَّد للباك-إند — مرجع تاريخي لمسارات `app-routes` عند الحاجة |
| `check-dev-server.mjs` | فحص أزرار اللوحة ضد قاعدة حية — يعمل يدويًا من هنا مع مكدس حي |
| `check-integration.mjs` | فحص الربط الثلاثي (تطبيق↔خادم↔لوحة) — يعمل يدويًا مع مكدس حي |

أُخرجت من الشجرة الحية لأنها **غير موصولة** (لا `package.json` ولا CI يستدعيها) ولمنع
إغراء تشغيل الوهمي بدل الحقيقي. التشغيل اليدوي: `node dev-server/server.cjs` ثم سكربت الفحص.
