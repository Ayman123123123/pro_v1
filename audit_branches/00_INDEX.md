## كيف تقرأ كل ملف

### 1) `branch_matrix.csv` — أعمدة كل صف

| العمود | المعنى |
|---|---|
| `branch` | اسم الفرع البعيد (بدون `origin/`) |
| `last_commit_date`, `author`, `subject` | آخر commit في الفرع |
| `commits` | عدد commits في الفرع |
| `ahead_of_main` | commits في الفرع غير موجودة في `main` |
| `behind_main` | commits في `main` غير موجودة في الفرع (= 371 لكل الفروع) |
| `files_in_branch` | عدد ملفات شجرة الفرع |
| `identical_to_main`, `pct_identical` | عدد ونسبة ملفات `main` المتطابقة **بايت-ببايت** |
| `only_in_branch` | مسارات موجودة في الفرع فقط |
| `only_in_main` | مسارات موجودة في `main` فقط (غائبة عن الفرع) |
| `modified` | مسارات موجودة في الاثنين لكن بصمة Blob مختلفة |
| `modified_old_version_in_main_history` | من `modified`: نسخة الفرع **قديمة وموجودة في تاريخ `main`** → لا شيء ضائع |
| `modified_unique_content` | من `modified`: نسخة الفرع تحوي **محتوى فريد** → يستحق المراجعة |
| `added_files_whose_content_is_in_main_history` | من `only_in_branch`: محتواها موجود في `main` بمسار آخر → **ملف مكرّر** |
| `added_files_unique_content` | من `only_in_branch`: محتوى فريد → يستحق الاستعادة |
| `pairs_ws_only`, `pairs_crlf_diff`, `pairs_bom_diff`, `pairs_final_newline_diff` | الفروق الحرفية لكل فرع |

### 2) `unique_files_only_in_branches.csv`
الأعمدة: `branch`, `path`, `bytes`, `lines`
> هذه قائمة «الاستعادة الواجبة» — 41 ملفًا موزّعة على 8 فروع، أثقلها 25 ملفًا في `chore/platform-rebuild-baseline`.

### 3) `orphan_line_diffs.csv`
الأعمدة: `branch`, `path`, `lines_added_vs_main`, `lines_removed_vs_main`, `total_lines_branch`
> `lines_added_vs_main` = عدد الأسطر الموجودة في الفرع و**غير الموجودة في `main`** (مجموعها 32,215 سطرًا).

### 4) `line_level_unique_diffs.patch`
ملف نصّي عادي (يُفتح بأي محرر). لكل قسم:
```
### <branch>  ::  <path>  (+مضاف / -محذوف)
diff --git a/... b/...
@@ ... @@
-سطر من نسخة main
+سطر من نسخة الفرع (هذا هو المحتوى الفريد)
```

### 5) `main_only_files.csv`
الأعمدة: `path`, `branches_missing_it`, `branches`
> فلترة سريعة: الصفوف ذات `branches_missing_it = 30` هي **حصرية في `main`** (402 ملفًا = عمل جديد لا يوجد في أي فرع).

### 6) `char_level_differences.csv`
الأعمدة: `branch`, `path`, `attr_diff`, `whitespace_only`, `main_crlf`, `branch_crlf`, `main_final_nl`, `branch_final_nl`
- `attr_diff` قد يحتوي: `crlf`, `bom`, `final_nl`, `trailing_ws` (أو أكثر من واحد مفصولة بـ `+`).
- `whitespace_only = True` = الملفّان متطابقان بعد تطبيع المسافات → **فرق بلا أي أثر وظيفي**.

### 7) `per_branch/<branch>.txt`
- **القسم 1** `name-status`: الحرف الأول يحدّد الحالة
  - `A` = الملف موجود في الفرع فقط
  - `D` = الملف موجود في `main` فقط (**غائب عن الفرع**)
  - `M` = معدّل بين الفرع و `main`
  - `R100` = نفس المحتوى لكن المسار اختلف (نقل/إعادة تسمية) — العمود الثاني مسار `main`، الثالث مسار الفرع
- **القسم 2** `numstat`: `أسطر مضافة <tab> أسطر محذوفة <tab> المسار`
