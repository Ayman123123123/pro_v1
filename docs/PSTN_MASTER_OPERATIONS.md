# الدليل الموحد لعمليات PSTN — منصة RED Sovereign

هذا الدليل يجمع كافة المعلومات الضرورية لإدارة وصيانة وتصحيح أخطاء نظام PSTN المرتبط ببوابات DINSTAR.

---

## 1. البنية التحتية (Architecture)

يتكون مسار المكالمة من:
1. **تطبيق الأندرويد**: يستخدم WebRTC عبر WSS للتحدث مع Asterisk.
2. **Asterisk**: يعمل كجسر (Bridge) بين الويب و GSM. يستخدم `pjsip` و `AMI`.
3. **DINSTAR UC2000-VE**: بوابة GSM الفيزيائية التي تحتوي على شرائح الاتصال.
4. **Backend Server**: يدير توزيع الأحمال (Load Balancing)، الربط الدائم (SIM Binding)، والتحكم في البوابات عبر HTTP API.

---

## 2. إدارة الأرقام (SIM Number Learning)

مشكلة أرقام سبأفون التي تظهر "فارغة" يتم حلها آلياً عبر خدمة `AutoNumberLearningService` أو يدوياً عبر:
- **المسار**: `Human Behavior -> Phone Number Learning` في واجهة DINSTAR.
- **النمط الموصى به**: `Call Mode` (يتصل المنفذ بمنفذ آخر لالتقاط الرقم).
- **أتمتة RED**: الباك أند يحاول تفعيل هذا النمط تلقائياً للمنافذ المفقودة كل ساعة.

---

## 3. تصحيح الأخطاء (Troubleshooting)

### سقوط أحداث المكالمات الواردة
إذا كانت المكالمات لا ترن في التطبيق:
1. تأكد من أن Asterisk يستطيع الوصول للباك أند عبر `http://backend:8080/api/internal/pstn/incoming`.
2. تحقق من `PSTN_INTERNAL_SECRET` في ملف `.env`.
3. فحص سجلات `InternalPstnController` في الباك أند.

### جودة الصوت ونغمة الرنين
- نستخدم `Progress()` في Asterisk لتمرير نغمة الرنين الحقيقية من المشغل (Early Media).
- تجنب استخدام `Ringing()` للمكالمات الصادرة إلى PSTN لأنها تولد نغمة وهمية وتخفي رسائل الشبكة.

## 4. أكواد USSD الهامة (اليمن)

| المشغل | معرفة الرصيد | معرفة الرقم |
|---|---|---|
| **سبأفون** | `*100#` | لا يوجد كود ثابت (استخدم نمط Call) |
| **يمن موبايل** | `*181#` | اتصل بـ `184` |
| **YOU** | `*444#` | `*111#` |
| **واي** | `*100#` | `*101#` |

## 5. الأوامر السريعة (CLI)

- **فحص حالة البوابات**:
  ```bash
  curl -H "X-Internal-Secret: ..." http://localhost:8080/api/internal/pstn/status
  ```
- **إعادة تشغيل منفذ**:
  ```bash
  # عبر الباك أند
  curl -X POST http://localhost:8080/api/admin/pstn/ports/0/reset
  ```
