## 3) عمودها الفقري — `api.ts` (764 سطر — 74 دالة)

### 3.1 طبقة المصادقة (4 دوال)
| الدالة | المسار الحرفي | التفصيل |
|---|---|---|
| `authStore` | `sessionStorage red_admin_access` + `localStorage red_admin_refresh` — `set(access,refresh?)` — `clear()` ترسل `younes:auth-expired` — `isAuthenticated` | Access في الذاكرة المؤقتة (يُمسح بإغلاق التبويب)، Refresh في التخزين الدائم |
| `rotate()` | `POST /api/auth/refresh {refreshToken}` → `set(access,refresh)` وإلا `clear()` — يحتفظ بالـ refresh عند انقطاع الشبكة المؤقت | دوران صامت |
| `apiFetch(path, init, retry=true)` | `Headers Content-Type json` + `Authorization Bearer access` + `fetch(path,init)` → إذا `401 && retry && rotate()` → إعادة المحاولة مرة واحدة | كل دوال الـ API تمر هنا |
| `adminLogin(username,password)` | `POST /api/auth/login` → إذا `!ok || user.role!='ADMIN'` throw → `set(access,refresh)` | يتحقق دور ADMIN |
| `adminLogout()` | `POST /api/auth/logout {refreshToken}` best-effort → `clear()` | إبطال refresh |

## 7) نقاط القوة والفجوات — حرفياً

**قوة:**
- 74 دالة `apiFetch` موحدة مع 401→rotate تلقائي — لا token مكشوف
- 12 صفحة lazy + Suspense — لا تحميل مبدئي ثقيل
- ثيم داكن RTL متقن (#050A16, #00C896, Cairo/Tajawal) — ليس ترجمة آلية
- فحص تعاقدي + vite preview كامل + Docker non-root
- لا اتصال مباشر بـ DB — كل شيء عبر `apiFetch`

**فجوة:**
- بعض التبويبات القديمة (Media/Backup 16–23 سطر) placeholder — يجب إخفاؤها أو ربطها بـ MediaAccessService
- `Dashboard` يعتمد `getRealtimeMetrics` الذي يحتاج backend حي — بدونه يظهر Alert warning
